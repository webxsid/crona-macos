# Crona for macOS v1.0.0-beta.10

Crona for macOS v1.0.0-beta.10 brings more of the daily workflow into the native menu-bar app: check in on wellbeing, keep an active timer visible, and create issues without switching to the terminal.

## Highlights

- Create an issue directly from the menu bar with title, estimate, repo, stream, description, and Today planning.
- Use familiar TUI-style estimates such as `45m`, `1h30m`, or `1h34m23s`.
- Record today's wellbeing check-in from a dedicated popover tab.
- Keep the current timer visible with the optional floating timer HUD.
- Navigate the reorganized Settings window with clearer categories and controls.

## Added

- A full-surface quick issue creator backed by the daemon's issue creation IPC contract.
- Searchable repo and stream selection with the active context selected when available.
- A Today option and post-creation Start Focus action for planned issues.
- Daily wellbeing fields for mood, energy, stress, sleep quality, and notes.
- A preference-controlled floating timer HUD.

## Changed

- Quick issue creation replaces the menu-bar dashboard while active and returns with a directional navigation transition.
- The issue creator uses one fixed panel size; opening destination selection or More Options does not resize the window.
- Settings now use a consolidated sidebar and detail hierarchy with native macOS toolbar styling.
- Issue creation errors and validation remain in context without leaving the creation surface.

## Fixed

- The Add control remains accessible at the leading edge of the menu-bar header.
- Repo and stream selection no longer relies on a cramped inline menu.
- Issue-creation transitions no longer leave invisible controls interactive or repeatedly resize the panel.

## Compatibility

- Tag this release as `v1.0.0-beta.10`.
- The Apple marketing version remains `1.0.0`; the build number is `11` for Sparkle appcast ordering.
- The daemon must report protocol version `1.3` during handshake.
