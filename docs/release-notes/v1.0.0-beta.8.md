# Crona for macOS v1.0.0-beta.8

Crona for macOS v1.0.0-beta.8 improves Pomodoro behavior, daemon compatibility, and timer-driven UI reliability.

## Highlights

- Keep the break screen from interrupting active typing or dragging.
- Start breaks early, start focus, or end breaks directly from the menu-bar popover.
- Keep countdowns, “Ends At”, warnings, reminders, and break-screen values synchronized with the daemon.
- Recover cleanly when notification delivery access is unavailable.

## Added

- Configurable activity-based break deferral with bounded per-session extensions.
- Pomodoro advance controls in the menu-bar timer view.
- A direct install/update link for daemon protocol mismatches.

## Changed

- The companion now uses protocol version `1.2` and Swift 6 concurrency semantics.
- Timer projections and warning indicators recalculate from authoritative daemon snapshots after advances, extensions, and expiry.
- Notification reconciliation and activation-policy updates avoid duplicate side effects.

## Fixed

- Revoking notification delivery access no longer causes recursive Combine updates and sustained CPU usage.
- Stale warning countdowns and end-time projections are cleared after Pomodoro transitions or expiry.
- Pomodoro timer actions remain guarded against stale notification responses.

## Compatibility

- The release remains on the `1.0.0` beta line and should be tagged as `v1.0.0-beta.8`.
- The Apple marketing version stays `1.0.0`; the build number increases to `9` for appcast ordering.
