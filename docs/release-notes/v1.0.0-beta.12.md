# Crona for macOS v1.0.0-beta.12

Crona for macOS v1.0.0-beta.12 focuses on a cleaner native Settings experience and faster ways to get back to Crona from anywhere on your Mac.

## Highlights

- Control whether Crona appears in the menu bar.
- Record an optional global shortcut to open Settings, with live feedback as you press a chord.
- Use a rebuilt Settings window with a translucent sidebar, native window controls, and a focused toolbar.

## Added

- A Menu Bar setting to show or hide the status item.
- An optional user-recorded global shortcut for opening Settings.
- Live recording feedback above the shortcut control, including modifier-key state and saved-shortcut confirmation.

## Changed

- Settings now use a dedicated AppKit-backed window shell with native traffic lights, a translucent sidebar, and a compact title toolbar.
- Opening Crona from the application bundle now presents the menu-bar popup when available; when it is hidden, Crona opens Settings instead.

## Compatibility

- Tag this release as `v1.0.0-beta.12`.
- The Apple marketing version remains `1.0.0`; the build number is `13` for Sparkle appcast ordering.
- The daemon must report protocol version `1.3` during handshake.
