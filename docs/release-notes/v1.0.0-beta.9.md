# Crona for macOS v1.0.0-beta.9

Crona for macOS v1.0.0-beta.9 hands automatic Pomodoro break deferral to the daemon and updates the companion to protocol version `1.3`.

## Highlights

- Break deferral is now coordinated through daemon alert delivery ACKs.
- Timer state, context, daily focus, and popover statistics stay synchronized with daemon warning and deferral events.
- The companion no longer maintains a competing activity timer or direct break-deferral request path.
- Away Today, historical away summaries, and red Stats calendar dates match the core TUI semantics.
- Idle menu text can show issue progress, total work-plus-break time, or today's focus score.
- Away dates remain distinguishable without color and expose their state, selection, and score to VoiceOver.

## Added

- Alert action decoding for break-deferral session and suggested-duration metadata.
- Action-bearing `alerts.delivery.ack` requests with configured extension seconds.
- Curated beta.9 changelog and release notes.
- A daemon-driven Target tile based on the selected day's issue estimates.

## Changed

- The companion now targets daemon protocol version `1.3`.
- Activity Guard uses recent keyboard and drag activity to decide whether to request the daemon ACK action.
- Maximum Deferral and companion-owned per-session cap enforcement were removed because the daemon owns validation and limits.
- Refresh handling now includes `timer.break_deferral_warning` and `timer.break_deferred`.
- Core settings reload from `settings.changed`, popup opening, and app activation for cross-client consistency.
- Stats date presentation is localized, and calendar animations and contrast follow macOS accessibility display preferences.
- Release CI runs optimized unit tests before signing and packaging begin.

## Fixed

- Disabling an ad-hoc away day now exits the live Away view while preserving the date in historical Stats.
- Browsing historical Stats no longer changes today's idle menu-bar metrics.
- Away actions show save progress and daemon errors instead of failing silently.
- Today metrics and focus score tolerate independent daemon failures instead of blocking each other.
- Calendar score prefetching preserves complete cached day summaries.

## Compatibility

- The release remains on the `1.0.0` beta line and should be tagged as `v1.0.0-beta.9`.
- The Apple marketing version stays `1.0.0`; the build number increases to `10` for appcast ordering.
- The daemon must report protocol version `1.3` during handshake.
