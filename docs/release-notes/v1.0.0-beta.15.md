# Crona for macOS v1.0.0-beta.15

Crona for macOS v1.0.0-beta.15 adds clearer context to hard-limit decisions and introduces continuous validation for changes landing on `main`.

## Highlights

- See how much time has been spent in the current session when the hard limit is reached.
- Review the same spent-versus-limit context while choosing an extension.
- See a completion-oriented session summary before committing the end-session note.
- Run macOS unit tests automatically on pushes and pull requests targeting `main`.

## Fixed

- Committing paused or running stopwatch sessions no longer fails while decoding the daemon's `timer.end` response.

## Compatibility

- Tag this release as `v1.0.0-beta.15`.
- The Apple marketing version remains `1.0.0`; the build number is `16`.
- The daemon must report protocol version `1.5` during handshake.
