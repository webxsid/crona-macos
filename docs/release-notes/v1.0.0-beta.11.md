# Crona for macOS v1.0.0-beta.11

Crona for macOS v1.0.0-beta.11 refines the floating timer experience and makes wellbeing’s empty-day state behave like a normal, editable form.

## Highlights

- Configure the floating timer’s default position and choose Compact, Regular, or Spacious sizing.
- Preview the floating timer directly from Menu Bar settings.
- Use Compact timer actions inside the HUD without clipped or unreachable controls.
- Record a wellbeing check-in on a day that has no existing entry without seeing a false error.

## Added

- A six-dot floating timer position picker with Bottom Center as the default.
- Floating timer size presets and a live settings preview.
- Focused IPC coverage for empty, valid, and malformed wellbeing responses.

## Changed

- Compact floating timer actions are revealed inside the timer surface on hover.
- Floating timer sizing and position preferences apply to the active HUD and persist across launches.
- The floating timer End action now transitions cleanly into its inline commit form and restores the timer view after Cancel or completion.
- Menu-bar popup presentation remains fixed-size and avoids resize oscillation during state updates.

## Fixed

- Compact floating timer buttons no longer render outside the panel or become clipped.
- Floating timer action buttons remain directly clickable.
- A missing wellbeing check-in is treated as a valid empty result instead of “The daemon returned an invalid response.”

## Compatibility

- Tag this release as `v1.0.0-beta.11`.
- The Apple marketing version remains `1.0.0`; the build number is `12` for Sparkle appcast ordering.
- The daemon must report protocol version `1.3` during handshake.
