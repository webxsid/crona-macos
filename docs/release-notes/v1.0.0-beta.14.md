# Crona for macOS v1.0.0-beta.14

Crona for macOS v1.0.0-beta.14 brings full habit management to the menu-bar companion and updates the daemon protocol expectation to `1.5`.

## Highlights

- Create, edit, and delete habits without leaving the menu-bar popover.
- Use the same repository and stream drill-down picker as issue creation.
- Choose daily, weekday, or custom schedules with explanatory subtitles and weekday chips.
- Manage habits from kebab menus, secondary-click menus, and habit details.
- Browse historical focus scores from a dedicated Stats calendar, with month navigation and future-month protection.
- Reconcile the companion's functional date with the daemon whenever the menu-bar popover opens.

## Compatibility

- Tag this release as `v1.0.0-beta.14`.
- The Apple marketing version remains `1.0.0`; the build number increases from `14` to `15`.
- The daemon must report protocol version `1.5` during handshake.
- The daemon must support the `dashboard.focus_score_range` date-range event for historical calendar data.
