# Crona for macOS v1.0.0

Crona for macOS 1.0.0 is the first stable release of the native Crona client. It brings the core Crona daily-work loop to a focused macOS menu-bar experience while keeping the daemon as the source of truth for timers, settings, dates, alerts, focus data, and mutations.

## Highlights

- Run focus sessions, breaks, extensions, and hard-limit decisions from the menu bar.
- Manage issues and habits without switching to the terminal UI.
- Record wellbeing check-ins and manual focus sessions.
- Browse historical focus scores and Away days in a calendar-based Stats view.
- Keep the active timer visible with a configurable floating HUD.
- Use native Settings, an optional global shortcut, configurable menu-bar/Dock presence, and Sparkle updates.

## Daily workflow

- Create issues with title, description, estimate, repository, stream, and Today planning.
- Enter estimates using familiar formats such as `45m`, `1h30m`, and `1h34m23s`.
- Start focus immediately after creating an issue and manage issue status from its card.
- Edit or explicitly delete issues from action and secondary-click menus.
- Create, edit, complete, schedule, and delete habits with daily, weekday, or custom schedules.
- Choose habit repositories and streams through the same searchable destination picker used for issues.
- Record wellbeing values for mood, energy, stress, sleep quality, and notes.
- Log completed sessions with work/break duration, date, optional timing, commit message, and notes.

## Timer and break behavior

- Timer projections, countdowns, warnings, reminders, break screens, and end-time displays follow authoritative daemon snapshots.
- Start breaks early, start focus, or end breaks from the menu-bar timer surface.
- Activity-aware break deferral responds to recent typing or dragging while the daemon owns validation, limits, and timer transitions.
- Hard-limit screens show spent-versus-limit context while deciding whether to continue, selecting an extension, or committing the completed session.
- The floating HUD supports Compact, Regular, and Spacious layouts, configurable position, hover actions, and reliable inline completion.
- The HUD hides during hard-limit decisions and returns when focus continues.

## Stats, wellbeing, and Away Mode

- Browse complete historical months with daily focus-score rings and heat-map coloring.
- Navigate directly back to today and prevent navigation into future dates or months.
- Preserve today’s menu-bar metrics while browsing historical dates.
- Display Away/rest days with accessible non-color indicators and positive semantic treatment.
- Configure Away rules and ad-hoc Away state from Settings.
- Configure date presentation consistently across Issues, Habits, Wellbeing, and Stats.
- Load today’s metrics and focus score independently so one unavailable daemon endpoint does not block unrelated data.

## Native macOS experience

- Use a native Settings window with sidebar navigation, traffic lights, toolbar styling, and focused detail views.
- Record an optional global shortcut for opening Settings with live modifier/key feedback.
- Show or hide the menu-bar item and return to menu-bar-only mode when regular windows close.
- Keep popup surfaces fixed and stable during navigation, outside-click dismissal, state updates, and issue creation.
- Use VoiceOver-friendly state labels, accessible away markers, supported macOS symbols, stable hit targets, and accessibility-aware animation and contrast.

## Reliability and distribution

- Recover from missing or stale daemon discovery by resolving and launching supported local daemon candidates.
- Stop retrying after repeated daemon launch failures and expose a stable reconnectable error state.
- Detect protocol mismatches and provide a direct installation/update path.
- Reconcile settings, activation policy, notifications, and functional date across daemon events and app activation.
- Ship universal `arm64`/`x86_64` signed and notarized DMG and ZIP artifacts with dSYMs and checksums.
- Receive signed Sparkle updates through the stable release channel.
- Validate macOS unit tests on pushes and pull requests targeting `main`.

## Compatibility

- Marketing version: `1.0.0`.
- Build number: `18`.
- Required daemon protocol: `1.5`.
- The matching daemon must support `habit.create`, `habit.update`, `habit.delete`, `dashboard.focus_score_range`, the session and issue mutation methods used by the companion, and daemon-owned break-deferral acknowledgement and timer transition behavior.

Crona for macOS is a client for the Crona daemon and does not replace the daemon or terminal UI. Install or update the compatible daemon before using protocol-dependent features.
