# Crona for macOS Docs

This docs set covers the native macOS client only. It does not try to duplicate the product-wide concepts, CLI behavior, or daemon design that already live in the main Crona repository.

## In This Repository

- [Install](install.md): app installation, channels, and update behavior
- [Runtime](runtime.md): runtime directory, discovery files, and daemon connection model
- [Development](development.md): local build and test workflow
- [Release](release.md): release tagging, signing, notarization, Sparkle, and GitHub Pages feed publication
- [Troubleshooting](troubleshooting.md): common runtime, notification, and update issues
- [Changelog](changelog.md): notable macOS app changes and release history
